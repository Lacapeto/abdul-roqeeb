Ongoing — Personal Project

Autonomous Vacuum Robot (ASVR)

An ESP32-brained, Arduino-Uno-driven vacuum cleaner robot. The ESP32 runs a lightweight HTTP command server that forwards instructions to the Uno over UART, which handles line-following-free obstacle avoidance, dustbin-level monitoring via ultrasonic sensing, and vacuum-motor control through a relay. A dedicated ESP32-CAM streams live video, which a Python script uses to run YOLO-based person detection and tracking for an autonomous "follow-me" mode.

Being paired with a custom Flutter mobile app (built in Android Studio) that will provide manual driving controls, a live camera view, and dustbin/battery gauges — replacing an earlier Blynk-based dashboard.

ESP32Arduino UnoC/C++ Python + YOLOFlutterUART / HTTP
Academic Project

IoT-Based Smart Wristwatch for Student Vital Signs Monitoring

A wearable health-monitoring concept designed for ABU's sick bay. Simulated in Proteus using an ESP32-WROOM microcontroller with a heart-rate sensor, DHT11 temperature/humidity sensor, an OLED display, and LED alerts for abnormal readings.

Paired with a companion web dashboard — the "ABU Sick Bay Smart Vital Signs Management System" — featuring Chart.js visualisations, student registration, real-time alert notifications, and a simulation-injection interface for testing.

ESP32-WROOMProteusChart.jsIoT Dashboard
Academic Project

Smart Walking Stick

A mechatronic assistive-device project for a Mechatronics course, simulated fully in Proteus 8. Involved sensor selection (an IR distance sensor for obstacle detection and an SG90 servo as a fold actuator), mathematical modelling, closed-loop control design, and a full technical report — completed with a formal group examination.
